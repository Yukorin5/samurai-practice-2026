# Indian Cinema Site

**Namaste Cinema** — インド映画と音楽を初めて楽しむ人に向けた、日本語の1ページサイトです。

## ダウンロードして開く

GitHub上のHTMLファイルはソースとして表示されます。サイトとして見る場合は、以下をダウンロードしてブラウザーで開いてください。

1. [Namaste-Cinema.zip](downloads/Namaste-Cinema.zip) を開き、GitHubの **Download raw file**（ダウンロードアイコン）から保存します。
2. ZIPを展開（解凍）し、中の `namaste-cinema.html` をChrome、Edge、Safariなどで開きます。

[単体HTML](downloads/namaste-cinema.html) を **Download raw file** から保存して開くこともできます。単体版には画像・CSS・JavaScriptがすべて含まれ、追加ファイルやインストールは不要です。外部の映画・音楽リンクを開くときだけ接続が必要です。

ブラウザーでローカルHTMLが制限される場合は、ZIPの展開先で `python3 -m http.server 8000` を実行し、ブラウザーからポート8000の `/namaste-cinema.html` を開いてください。

## 起動方法

追加パッケージやビルドは不要です。Python 3 がある環境では、リポジトリのルートから以下を実行します。

```sh
python3 -m http.server 8000 --bind 0.0.0.0 --directory indian-cinema-site
```

ブラウザーでポート8000の `/` を開いてください。終了は `Ctrl+C` です。

## 内容と操作

- インド映画の歴史と、地域・言語による映画産業の違い
- 俳優4人・女優4人のカード（各人物200文字以内）
- 初心者におすすめの映画3本、音楽4曲
- 人物の俳優／女優フィルター、音楽の気分フィルター
- モバイルメニュー、キーボード操作、動きを減らす設定への対応
- 予告編・楽曲のYouTube検索リンク、参考情報の開閉

HTML、CSS、JavaScriptとローカルのSVGで構成しています。外部フォント・ライブラリ・APIキーは不要です。外部リンクを開く場合のみインターネット接続が必要です。肖像・作品の絵はオリジナルのイメージイラストで、写真や公式ポスターではありません。

## ファイル

| ファイル | 内容 |
| --- | --- |
| `index.html` | 日本語の掲載内容・ページ構成 |
| `styles.css` | PC・タブレット・スマートフォンのレイアウト |
| `script.js` | メニュー、フィルター、現在のセクション表示 |
| `assets/` | イラストとサイトアイコン |
| `downloads/` | 画像・デザイン・操作機能を含む単体HTMLとZIP |
| `build_download.py` | 単体版を再生成するPythonスクリプト |

掲載内容やデザインを変更したら、以下で単体版を再生成できます（Python 3.9以降、追加パッケージ不要）。

```sh
python3 indian-cinema-site/build_download.py
```

## 検証

Chromiumで320・390・640・768・1024・1440pxの画面幅を確認。PCとスマートフォンのWCAG 2.1 A/AA自動チェック（axe-core）で検出違反0件。画像の読み込み、横スクロールの有無、ページ内リンク、モバイルメニュー、Escapeキー、人物・音楽フィルター、参考情報の開閉を検証しています。

単体HTMLも1440・390pxで画像表示・人物／音楽フィルター・モバイルメニューを確認しています。追加ファイルの通信が発生しないこと、ZIPの整合性と再生成結果の一致も検証しています。

通常の静的サイトホスティングにもそのまま配置できます。この作業では公開・デプロイは行っていません。
